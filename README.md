Everything you need to build your own CLI, for humans and AI agents alike. Cliron gives you the features you'd expect out of the box, and lets you change any of them to fit your tool. It installs nothing else, and works just as well for the AI agents running your CLI as for the people using it.

## Installation

```bash
pip install cliron
```

## Requirements

- **Python**: 3.11 or higher
- **Rust**: 1.96 or higher
- **uv**: 0.11 or higher
- **just**: 1.52 or higher
